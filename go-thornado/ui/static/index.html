Operator Bond

          

            

              Bond from shielded notes
              
Deposit as a user first, then spend notes into transparent bond_escrow via MsgBondFromNotes. No separate bond BTC deposit.

              
              
              

                
              

            

            

              Auction bid (shield → unshield → bid)
              
Create a bid, then redeem shielded notes with recipient_policy: bid_deposit to the protocol escrow and the bid id. Seller settles the auction, shields the sale entitlement, then unshields payout notes normally.
